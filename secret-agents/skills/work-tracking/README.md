# Work Tracking

Manual receipts, daily context, source-qualified Perforce and GitHub evidence, reports, and Jira intake workflows.

Canonical work-tracking workflows resolve their data through `work-tracking/v1` and its named locations. The published
workflow set is `daily-note-create`; `perforce-receipt-create`, `perforce-receipt-range`, and `perforce-rollup`;
`git-receipt-create`, `git-receipt-range`, and `git-rollup`; and `report-receipt`, `report-status`, and `report-rollup`.
The retired `checkin-*` names have no compatibility aliases.
