# Work Tracking

Manual receipts, daily context, source-qualified Perforce and GitHub evidence, reports, and Jira intake workflows.

Canonical work-tracking workflows resolve their data through `work-tracking/v1` and its named locations. The current
source-control workflow names are `perforce-receipt-create`, `perforce-receipt-range`, and `perforce-rollup`; the
retired `checkin-*` names have no compatibility aliases.
