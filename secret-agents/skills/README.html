Handbag of Holding Agent Skills

This guide inventories the 29 canonical workflows in the shared skills library. Canonical sources live in manifest-declared collections; the catalog publishes installable adapters under _generated. Read the root README, then the applicable collection README and canonical SKILL.md before changing any workflow.

The catalog and TOC are catalog-owned. This Markdown file is rendered to README.html; do not edit that HTML directly.

How skills are wired and invoked

Use each workflow by its canonical name. The installer reads catalog.json and links the matching _generated/<canonical-name> adapter into a harness mixing directory. An adapter forwards to the single authored source, so a workflow has one instruction owner.

To publish source changes, run the catalog update and check commands from the root README, then render this guide. A collection README explains its boundary; collections.json remains the machine-readable authority for collection names and ordering.
